A six-legged robot,

Hexapodcpp drives an 18-DOF hexapod with inverse kinematics, multiple gaits and a layered, embedded-friendly C++ core, then lets you steer it from a live 3D web cockpit.

Features

Everything a walking robot needs

Locomotion

Inverse kinematics for every leg, with tripod, wave and ripple gaits and body posture control.

Sensor fusion

MPU-9150 IMU with AHRS, barometer, ultrasonic and laser time-of-flight proximity sensing.

Power awareness

Battery voltage and current monitoring through an ADS1115 ADC, surfaced in the cockpit.

Sound reaction

GPIO sound detection with LED feedback, so the robot reacts to the room around it.

Many ways to drive

PS3 gamepad, keyboard, virtual stick, or point-and-go: click the floor and the hexapod walks there.

Quality gates

GoogleTest and GMock suites, coverage, cppcheck and clang-tidy, all wired into CI.

Architecture

Layered, observable, no exceptions

Each layer has one job. Dependencies are composed statically in the application root.

  1. 01

    Driver

    Low-level hardware and OS access: GPIO, I²C, sockets.

  2. 02

    Component

    Stateful hardware abstractions that notify observers when values change.

  3. 03

    Service

    Orchestration and behavior: gait, body, sensing, and safety logic.

  4. 04

    Cluster

    Protocol handlers that answer request and response frames from the cockpit.

Quick start

Run it on your machine

Builds are scripted for Debian, Ubuntu and WSL. On Windows, run scripts through WSL.

Simulation and tests
# Build & run the controller on your PC
bin/dev/build.sh X64 sources DEBUG
./build/hexapod-X64-DEBUG/src/Hexapodcpp

# Run the unit tests
bin/dev/test.sh all
Web cockpit
cd HMI
npm install
npm run dev      # http://localhost:5173
